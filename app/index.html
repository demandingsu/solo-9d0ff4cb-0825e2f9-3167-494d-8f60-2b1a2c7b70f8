市政工程投标公告采集 API

接口

  • POST /api/collect — 传入 {"catalog_url": "..."} 触发采集，成功后整体替换旧结果，失败保留旧结果
  • GET /api/tenders — 各标段当前投标截止时间汇总（冲突标段 status=conflict）
  • GET /api/tenders/{招标编号} — 单标段有效公告链、失效原因与来源链接
  • GET /api/raw — 最近一次采集的原始公告数据
  • POST /api/station-check — 桩号核查：输入线路编号、起止桩号与路段目录 URL，报告缺段/重叠及来源
  • GET /docs — Swagger 交互文档
  • 离线分页 HTML 公告样例（/sample，纯静态无外部依赖）
  • 离线分页路段表样例（桩号核查用）

典型流程

  1. 打开 样例目录，复制目录第一页 URL
  2. 调用 POST /api/collect 采集
  3. 调用 GET /api/tenders 核对截止时间；冲突标段进入详情查看冲突公告来源
  4. 桩号核查：调用 POST /api/station-check，例如 {"lineCode":"LX-2026-A","startStation":"K0+000","endStation":"K3+500", "catalogUrl":"http://localhost:8000/sample/segments/page_1.html"}
